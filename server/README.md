# BookPulse Express API

## Instalar
```bash
cd server
npm install
```

## Ejecutar
```bash
npm start
```

API:
- `GET http://localhost:3000/api/books`
- `GET http://localhost:3000/api/books?q=angular`

Para usarla desde el emulador, expón el puerto con ngrok y coloca la URL HTTPS en:
`src/app/core/app-config.ts`
