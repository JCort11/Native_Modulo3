## Flujo completo

Buscar:
`SearchComponent -> BooksApiService -> Express -> querystring -> resultados`

Favorito:
`Search -> addFavorite action -> booksReducer -> selectFavorites -> Favorites`

Leer ahora:
`Favorites -> readNow action -> booksReducer -> selectReadingNow -> Settings`
